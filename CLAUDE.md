# OMG Serviteca, instrucciones para Claude Code

Lee y cumple `AGENTS.md` antes de modificar cualquier archivo.

El repositorio y `master` son la fuente compartida entre Claude Code y Codex.

Al iniciar:
1. Verifica Git.
2. Sincroniza de forma segura con `origin/master`.
3. Lee `docs/OMG_UX_REDESIGN.md`.
4. Lee `docs/BITACORA.md`.
5. Continúa desde el estado actual. No reviertas trabajo de Codex por no reconocerlo.

Al finalizar:
1. Prueba los cambios.
2. Actualiza `docs/BITACORA.md`.
3. Commit.
4. Push a `origin/master`.
5. Confirma sincronización.

No uses comandos Git destructivos para resolver diferencias.
