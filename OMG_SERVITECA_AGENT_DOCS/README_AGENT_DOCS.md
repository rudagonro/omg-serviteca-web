# Documentación de agentes, OMG Serviteca

Este paquete contiene instrucciones compartidas para trabajar el sitio con Codex o Claude Code.

Archivos:
- `AGENTS.md`: reglas permanentes, Git, `main`, sincronización y cierre.
- `CLAUDE.md`: entrada específica para Claude Code.
- `docs/OMG_UX_REDESIGN.md`: plan de reorganización UX.
- `docs/BITACORA.md`: tareas, decisiones y continuidad entre agentes.

Copiar estos archivos a la raíz del repositorio respetando las rutas indicadas.

Antes de trabajar, el agente debe leer `AGENTS.md`, el plan UX y la bitácora.
